# การตรวจสอบก่อนสั่งซื้อ

คำศัพท์สำหรับการช่วยผู้ซื้อค้นหาประเด็นที่ควรตรวจ ก่อนตัดสินใจสั่งซื้อสินค้า

## Language

**การตรวจความเสี่ยงเบื้องต้น**:
การระบุประเด็นความเสี่ยงที่เกี่ยวข้องกับสินค้าและบริบทการซื้อ พร้อมสิ่งที่ควรตรวจต่อ รวมถึงประเด็นที่ผู้ซื้อยังไม่ได้นึกถึง โดยไม่ได้หมายถึงการรับรองว่าครอบคลุมทุกความเสี่ยง

**กรณีซื้อ (Purchase case)**:
สินค้าที่ผู้ซื้อกำลังพิจารณาในบริบทและข้อกำหนดชุดเดียวกัน รวมตัวเลือกที่ต้องการซื้อไว้ในงานตรวจเดียว

**ตัวเลือกสินค้า (Option)**:
แบบของสินค้าที่ผู้ขายแยกให้เลือก เช่น สีหรือลาย ซึ่งอาจมีคุณสมบัติหรือหลักฐานต่างจากแบบอื่นในหน้าเดียวกัน

**หลักฐาน (Evidence)**:
ข้อความ รูป หรือเอกสารที่ใช้รองรับข้อกล่าวอ้าง โดยการเป็นหลักฐานไม่ทำให้คำอ้างในนั้นเป็นข้อเท็จจริงที่พิสูจน์แล้ว

**ข้อค้นพบ (Finding)**:
ประเด็นที่ควรพิจารณาจากสินค้า ความต้องการ และหลักฐาน พร้อมสิ่งที่ยังไม่ทราบและสิ่งที่ควรตรวจต่อ ไม่จำเป็นต้องเป็นข้อบกพร่องที่ยืนยันแล้ว

**Purchase review**:
รายงานสำหรับกรณีซื้อหนึ่งกรณี ซึ่งเชื่อมข้อค้นพบกับตัวเลือก ความต้องการ หลักฐาน และงานที่ควรทำต่อก่อนตัดสินใจซื้อ
