Each claim has exactly one source:
- text_excerpt: quote an exact contiguous part of original_text, keeping numbers and their
  qualifications intact. Quote the entire original value for a shared selector.
  Include the units, range, and conditions with any written measurement.
  Use the single owning option ID for sources with claim_scope sku, or [] for claim_scope shared.

- image_measurement: use the clearly readable number and unit on a specific SKU's attached

  temperature_use. Use only the image_source_id mapped to the single option ID in the claim
  and present in attached_image_ids. A thumbnail label does not verify a delivered value.
- image_detail: select a visible detail from the schema for that SKU's attached thumbnail.

  cannot be represented by the schema, leave it unconfirmed instead of improvising a label.
